# 🤯 BRAINROT BOARD 9000

A soundboard with 44 meme sounds. Tap a button, it plays. That's it.

Live at **https://soundboard.kosta.lol**

## What the top buttons do

- **🎚️ NORMAL / SPED-UP** — same sound at normal speed or squeaky and fast.
- **💣 WALL OF NOISE** — plays all 44 sounds at once. Chaos.
- **🔊 BASS BOMB** — a huge deep bass drop that shakes the screen.
- **🎲 RANDOM** — plays a random sound.
- **🥪 SANDWICH** — stacks a bunch of sounds together.
- **🛑 STOP** — makes everything stop.
- **🚨 MAX CHAOS** — plays random sounds non-stop until you turn it off.
- **❓** — explains all the buttons.

## Running it

Just open `index.html` in a browser. No install needed.
